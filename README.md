# KAIJU LABS — Autonomous Bio-Robotics & Synthetic Ecology

> An Awwwards-inspired brutalist sci-fi digital experience showcasing autonomous biomimetic deep-sea and planetary exploration drones.

## Features

- **Real-Time 3D Drone Telemetry:** Interactive 3D inspection of the Apex K-09 sentinel drone with live cursor-tracking laser targeting and heading coordinates.
- **Dynamic Vision Shaders:** Instant toggle between three rendering passes:
  1. **PBR Surface:** Metallic roughness, emissive glow maps, and physical lighting.
  2. **Lidar Wireframe:** Holographic wireframe mesh with cyber-neon scanlines.
  3. **Infrared Thermal:** False-color thermal radiation gradient mapping.
- **Subsystem Diagnostic Audit:** Interactive health verification across synthetic myomer actuation, quantum lidar, cryo-hydrogen core, and neuromorphic edge compute.
- **Mission Deployment Terminal:** Interactive mission launcher for Challenger Deep, Olympus Mons, and Orbital Debris operations.
- **Procedural Cybernetic Sound:** Web Audio API synthesis generating sub-bass reactor hum and radar sweeps.
- **Lenis Smooth Scrolling:** Inertial scrolling across all viewports.

## Tech Stack

- **Framework:** React 18, Vite, TypeScript
- **3D Engine:** Three.js (r173) with GLTFLoader and ACESFilmic tone mapping
- **Styling:** Tailwind CSS, Tactical scanline overlays, CSS Grid
- **Audio:** Web Audio API procedural synthesis
- **Smooth Scroll:** Lenis Smooth Scroll
- **Icons:** Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
